⚡ How Environment Switching Works Seamlessly

YAWPS uses an NTFS Directory Junction at %USERPROFILE%\.yawps\current. When this directory is added to your User PATH, you can switch PHP versions instantaneously without restarting your IDEs or terminals!

Junction Point: C:\Users\username\.yawps\current
➜
Points to Target: None

💻 CLI Commands Cheat Sheet

yawps list List installed versions and active version
yawps install 8.3 Download and install PHP 8.3 (NTS x64)
yawps use 8.3 Switch active version to PHP 8.3
yawps update Check and install latest patch updates
yawps ext list List extensions and active status
yawps ext enable curl Enable extension in active php.ini
yawps uninstall 8.3 Uninstall PHP version and unlink junction
yawps env remove Remove YAWPS from Windows User PATH
yawps cleanup Full cleanup: unlink PATH and wipe data
yawps gui Launch this Desktop Window
